# Relatório web

Esta pasta é independente da implementação Python. Ela contém somente uma página estática que documenta o estado do projeto.

- `index.html`: conteúdo do relatório;
- `styles.css`: formatação do relatório;
- `abrir_relatorio.bat`: atalho opcional para abrir a página no Windows.

O relatório não executa coleta nem análise. Os resultados reproduzíveis permanecem em `..\notebooks\Trabalho PLN.ipynb`.
